Скрипт для автоматического получения курсов валют относительно доллара США (USD).

Алгоритм работы:
1. Получаем данные о курсах валют через открытй API https://www.exchangerate-api.com/
2. Делаем бекап данных и сохраняем в JSON-формате.
3. Парсим данные в датафрейм с полями Currency (код валюты) и Rate_to_USD (курс к доллару).
4. Сохраняем результат парсинга в файлы формата csv и xlsx.

Также реализовано базовое логирование, поэтому все действия записываются в консоль и в файл script.log.
Для корректной и безопасной работы с открытым API рекомендуется получить API-ключ и поместить его в
основную директорию проекта, в файл с расширением .env.
Для получения API-ключа перейдите по ссылке: https://www.exchangerate-api.com/.


Для локального запуска установите пакетный менеджер uv, если он не установлен. Подробнее о uv: https://docs.astral.sh/uv/
Склонируйте данный репозиторий проекта;
Установите виртуальное окружение командой uv venv и активируйте его:

Для Windiws:
```
.venv/Scripts/activate
```

Для Unix/MacOS:
```
.venv/bin/activate
```

Также для запуска потребуется наличие предустановленных библиотек:
```
uv add pandas dotenv requests openpyxl
```

- pandas, для работы с датафреймом;
- dotenv, для загрузки данных из переменных окружения;
- requests, для работы с http-запросами;
- openpyxl, для программного чтения excel форматов.
